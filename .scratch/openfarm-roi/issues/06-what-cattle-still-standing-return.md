# What cattle still standing return

Status: open

Type: grilling

Blocked by: 05

Map: [OpenFarm: what the money in cattle returns](../map.md)

## Question

The Owner wants the return while a run is still going, not only once it is sold. Decide how a standing animal enters it:

- **Her value today.** Priced as `fattening.prices` prices her (latest weight × the farm's market price a kilo for the Farm's own, the **Venture Plan**'s prices for a Venture's), at the low end, the high end, or both as a range?
- **Her money in so far.** Purchase and charged to date, as the animal prices already count.
- **A run part sold.** How the sold animals' results and the standing ones' values add up, and how the page says which part is fact and which is estimate.
- **A Venture.** Its **Projection** already estimates the Settlement. Does a running Venture's return come from the Projection, or from the same standing-value sum as the Farm's own run, and do the two agree?
- **The words.** How the figure says it is an estimate, never a result, so the Owner never takes it for one.
